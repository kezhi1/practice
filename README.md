# 刷题 · Practice

把 Markdown 当题目源文件，导入后变成可随机抽 50 题来刷的纯前端应用。数据全部存在浏览器本地（IndexedDB），离线可用、无需部署后端。

## 快速开始

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 类型检查 + 打包到 dist/
npm run preview  # 预览打包产物
```

端到端自检（需要本机 Edge，开发服务器在跑）：

```bash
npm test         # 解析器单元测试（vitest，19 个用例）
node scripts/e2e.mjs
```

它会走完「导入 → 题库 → 抽 50 题 → 作答 → 交卷 → 结果」全流程，把截图写进 `docs/shots/`，并收集控制台错误。

## Markdown 格式

一个文件 = 一个知识库；`##` 开一题；选项写列表；答案和解析写引用块。

```markdown
---
title: 计算机网络基础
tags: [网络, 面试]
---

## 1. TCP 三次握手中，第三次握手的作用是？

- A. 确认双方序列号
- B. 建立连接
- C. 防止旧连接请求
- D. 协商窗口大小

> 答案：A
> 解析：第三次握手让服务端确认客户端收到了自己的 SYN+ACK。
> 难度：2

## 2. 下列哪些协议是应用层协议？

- A. HTTP
- B. TCP
- C. DNS
- D. IP

> 答案：A,C
> 类型：多选

## 3. 交换机工作在数据链路层。

- A. 正确
- B. 错误

> 答案：对
> 类型：判断
```

| 字段 | 写法 | 说明 |
| --- | --- | --- |
| 知识库标题 | front matter `title:` | 缺省用文件名 |
| 标签 | `tags: [网络, 面试]` | 只用于展示与分类 |
| 题干 | `## 题干` | 支持行内 Markdown（`**粗体**`、`` `代码` ``） |
| 选项 | `- A. 内容` | 判断题也要写 `- A. 正确` / `- B. 错误` |
| 答案 | `> 答案：A` 或 `> 答案：A,C` | 判断题可写 `对` / `错` / `A` / `B` |
| 解析 | `> 解析：…` | 可写多行 `>` |
| 难度 | `> 难度：1–5` | 缺省 2 |
| 题型 | `> 类型：单选 / 多选 / 判断` | 不写则按答案与选项自动判断 |

### 宽容到什么程度

同一份 Markdown 可以有很多写法，下面这些都认：

| 想写的 | 认得的写法 |
| --- | --- |
| 分题 | `#` `##` `###` `####` 标题；全篇没有标题时按 `1.` `2.` 编号分题；都没有就当一题 |
| 选项 | `- A. 内容`、`- A、内容`、`A. 内容`、`A：内容`、`(A) 内容`、`- A 内容` |
| 答案 | `> 答案：A`、`答案 A`、`**答案：A**`、`【答案】A`、`正确答案是 B` |
| 多选 | `A,C`、`A、C`、`A C`、`AC`（连写也能拆） |
| 解析 | `> 解析：…`、`解析：…`、`分析：…`、`【解析】…`，可以写多行 |
| 判断题 | 写 `> 答案：对` 就行，选项自动补 `A. 正确 / B. 错误` |
| 题型/难度 | `> 类型：多选`、`> 难度：3`（也可以从答案个数自动判断） |
| 代码块 | ` ``` ` 里的 `##`、`- A.` 不会被当成新题 |

**严格模式：不猜你的意思。** 写法能认就认，但只要“意思”有歧义，一律报错拒收那一题（其它题照常导入），并指出第几行：

- 标成单选却给了多个答案 → 报错（不擅自改成多选）
- 标成多选却只有 1 个答案 → 报错
- 题型写了不认识的词（如“填空”）→ 报错
- 答案不在选项里、选项不足 2 个、缺答案 → 报错

只有“结构能唯一确定”的地方才补全，且一定在预览里提醒你（例如判断题没写选项，自动补 A.正确 / B.错误）。

导入时会**逐行校验**：缺答案、选项不足、答案不在选项里、跨题漏空行等都会在预览面板里报出「第 N 行 + 原因」，可以改完再导。同一知识库内题干重复的题会自动跳过。

## 规则

- **抽题**：先按知识库过滤，`Fisher–Yates` 洗牌后取前 50；不足 50 就全部出题。
- **题型**：单选 / 多选 / 判断。
- **判分**：答案集合完全一致才得分，多选漏选、错选均为 0 分。
- **记录**：每次交卷存一条练习记录；答错的题 `wrongCount + 1` 并记 `lastWrongAt`。
- **错题本**：`wrongCount > 0` 的题自动进错题本，跨知识库汇总；可以按「错得最多 / 最近错 / 按知识库」排、按知识库筛、搜索，单题「标为已掌握」（清零）。
- **错题练习**：从错题池里随机抽 50（不足全出）练；答错 +1，答对 −1（最低 0），也就是“熟悉度”在回升，答对了就慢慢退出错题本。
- **练习历史**：每次交卷留一条记录，按时间倒序列出得分/正确率/用时，可筛知识库；点「看回顾」直接回到那一次的逐题回顾。

  lib/util.ts          洗牌、集合比较、计时格式化

  views/ImportView.tsx 导入与预览

  views/Result.tsx     结果与逐题回顾
  views/WrongBook.tsx  错题本
